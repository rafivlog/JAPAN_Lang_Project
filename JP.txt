国際 (こくさい / Kokusai) — আন্তর্জাতিক (International)  
​交流 (こうりゅう / Kōryū) — পারস্পরিক বিনিময় / যোগাযোগ (Exchange / Interaction)  
​流れる (ながれる / Nagareru) — প্রবাহিত হওয়া (To flow)  
​流す (ながす / Nagasu) — ভাসিয়ে দেওয়া / ফেলে দেওয়া (To let flow / Flush)  
​流行 (りゅうこう / Ryūkō) — ট্রেন্ড / ফ্যাশন (Trend / Fashion)  
​参加 (さんか / Sanka) — অংশগ্রহণ (Participation)  
​持参 (じさん / Jisan) — সাথে আনা / বহন করা (Bringing along)  
​参る (まいる / Mairu) — আসা / যাওয়া [বিনম্র রূপ] (To go / To come)  
​増加 (ぞうか / Zōka) — বৃদ্ধি পাওয়া (Increase)  
​加わる (くわわる / Kuwawaru) — যোগ দেওয়া / যুক্ত হওয়া (To join / To be added)  
​加える (くわえる / Kuwaeru) — যোগ করা (To add)  
​申す (もうす / Mōsu) — বলা / নাম হওয়া [বিনম্র রূপ] (To say / To be called)  
​申し込む (もうしこむ / Mōshikomu) — আবেদন করা (To apply)  
​申し込み (もうしこみ / Mōshikomi) — আবেদনপত্র / ফরম (Application)  
​〜込む (こむ / Komu) — ভেতরে যাওয়া / ভিড় হওয়া (Into / Crowded)  
​込める (こめる / Komeru) — উজার করে দেওয়া [মন/ভালোবাসা] (To put into)  
​文化 (ぶんか / Bunka) — সংস্কৃতি (Culture)  
​化粧品 (けしょうひん / Keshōhin) — প্রসাধনী (Cosmetics)  
​〜化 (か / Ka) — রূপান্তর (-ization)  
​各〜 (かく / Kaku) — প্রতিটি (Each / Every)  
​各地 (かくち / Kakuchi) — বিভিন্ন স্থান (Various places)  
​各国 (かっこく / Kakkoku) — প্রতিটি দেশ (Each country)  
​誰 (だれ / Dare) — কে (Who)

  渋谷 (しぶや / Shibuya) — শিবুয়া [জাপানের একটি বিখ্যাত জায়গার নাম] (Shibuya)
  野原 (のはら / Nohara) — খোলা মাঠ / প্রান্তর (Field)

  原因 (げんいん / Gen'in) — কারণ (Cause / Reason)
  渡る (わたる / Wataru) — পার হওয়া / পারাপার করা (To cross)
  渡す (わたす / Watasu) — হস্তান্তর করা / তুলে দেওয়া (To hand over)
